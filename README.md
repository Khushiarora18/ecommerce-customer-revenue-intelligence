# E-Commerce Customer & Revenue Intelligence

### SQL | Power BI | DAX | Excel | Customer Analytics

An end-to-end business intelligence project designed to analyze e-commerce revenue, profitability, customer acquisition, purchasing behavior, and customer retention using a synthetic dataset covering **2024–2025**.

## Project Overview

This project transforms transactional e-commerce data into actionable business insights through MySQL analysis, data modeling, DAX calculations, and an interactive four-page Power BI dashboard.

**Business objectives:**

* Monitor revenue, profitability, and order performance.
* Identify revenue-driving product categories.
* Evaluate customer acquisition channels.
* Segment customers using RFM analysis.
* Identify high-value and at-risk customer groups.

## Dataset

The synthetic dataset contains five interconnected tables:

| Table       | Records |
| ----------- | ------: |
| Customers   |   8,000 |
| Products    |     150 |
| Orders      |  15,000 |
| Order_Items |  24,395 |
| Date        |     731 |

**Analysis period:** January 2024 – December 2025.

## Key Insights

**Revenue concentration:** Electronics contributes approximately **61.69%** of revenue but operates at an **11.07%** profit margin.

**Category profitability:** Beauty has a **38.22%** profit margin, while Fashion has a **33.67%** margin, indicating meaningful differences in category-level profitability.

**Customer segmentation:** RFM analysis separates customers into Champions, Loyal Customers, Potential Loyalists, At Risk, High Value - Inactive, New / Emerging, and Needs Attention groups.

**Retention opportunities:** The segmentation supports targeted investigation of customer retention, reactivation, and loyalty strategies.

## Methodology

1. Prepared a structured synthetic e-commerce dataset.
2. Imported five tables into MySQL.
3. Validated data quality and referential integrity.
4. Analyzed revenue, profitability, and customer behavior using SQL.
5. Created customer-level RFM metrics and segments.
6. Built a relational Power BI model.
7. Developed DAX measures and four interactive dashboard pages.
8. Conducted final dashboard quality checks.

This project uses **synthetic data** for portfolio demonstration and learning purposes. The findings illustrate analytical techniques rather than actual company performance.
